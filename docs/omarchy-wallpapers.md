# Omarchy wallpapers

The Omarchy profile stores selected wallpapers in `~/Pictures/Wallpapers`.
It links these images into the current theme's user background directory so
they appear in Omarchy's wallpaper switcher. A `theme-set` hook creates the
links again for each theme you switch to.

## Choose a wallpaper

Open the wallpaper switcher:

```sh
omarchy background
```

The default collection contains two SpaceX Starship launch images. Their sources
are under `/usr/share/omarchy/themes/`:

| Collection filename | Stock source relative to the themes directory |
| --- | --- |
| `spacex-liftoff.webp` | `tokyo-night/backgrounds/0-liftoff.webp` |
| `spacex-flight14-dawn.webp` | `starship/backgrounds/2-flight14-dawn.webp` |

To cycle through the current theme's backgrounds, run `omarchy theme bg next`.
You can also set an image directly from its path:

```sh
omarchy theme bg set "$HOME/Pictures/Wallpapers/spacex-liftoff.webp"
```

Sharing the collection makes these images available for selection after theme
changes. Omarchy still chooses the active wallpaper when it applies a theme.

## Directories and links

In the supported Omarchy 4.5 environment, the
[wallpaper switcher](https://github.com/omacom/omarchy/blob/quattro/bin/omarchy-theme-bg-switcher)
reads two directories:

- `~/.local/state/omarchy/current/theme/backgrounds`, generated by Omarchy.
- `~/.config/omarchy/backgrounds/<theme>/`, for the current theme's user images.

It has no built-in global wallpaper directory. It does not scan
`~/Pictures/Wallpapers` or the root of `~/.config/omarchy/backgrounds`.

The [wallpaper task](../tasks/desktop/omarchy/wallpapers.yml) copies the selected
stock images into the personal collection. Each theme uses a symbolic link to
that copy. For example, with Flexoki Light selected:

```text
~/.config/omarchy/backgrounds/flexoki-light/spacex-liftoff.webp
  -> ~/Pictures/Wallpapers/spacex-liftoff.webp
```

The [hook template](../templates/omarchy/wallpapers-theme-set.sh.j2) is installed
as `~/.config/omarchy/hooks/theme-set.d/90-proarch-wallpapers`. Ansible runs it
during setup. Without an argument, it reads the current theme slug from
`~/.local/state/omarchy/current/theme.name`. After a theme change, Omarchy passes
the new slug to the hook, which creates the links in that theme's user directory.

An existing link to the same image stays unchanged. If another file or link
occupies the destination, the hook renames it with a
`.proarch-backup-<timestamp>` suffix before creating the link. Ansible also backs
up existing collection files before replacing them. The packaged themes and
Omarchy's generated background directory remain under Omarchy's ownership.

## Configure the collection

Defaults live in [profiles/omarchy.yml](../profiles/omarchy.yml). Put host
customization under `omarchy_overrides` in `config.yml`:

```yaml
omarchy_overrides:
  wallpaper_dir: "{{ target_home }}/Pictures/Wallpapers"
  wallpapers:
    - src: /usr/share/omarchy/themes/tokyo-night/backgrounds/0-liftoff.webp
      name: spacex-liftoff.webp
    - src: /usr/share/omarchy/themes/starship/backgrounds/2-flight14-dawn.webp
      name: spacex-flight14-dawn.webp
```

`wallpaper_dir` is the collection directory for the resolved target user.
Each `src` is an absolute source path on the target machine; `name` is the
filename in the collection and in each theme's user background directory.
The `wallpapers` list replaces the complete default list, so retain the entries
you want when adding another image.

Apply changes through the [normal Omarchy playbook workflow](../readme.md#configure-and-run).
Ansible copies the images and renders the hook with the configured paths.
The hook handles only the images in this list. Dropping another file into the
collection does not add it to the switcher automatically.

Setting `wallpapers: []` skips the wallpaper tasks. Existing collection files,
theme links, and the installed hook remain in place. To stop automatic linking
after a previous installation, also remove
`~/.config/omarchy/hooks/theme-set.d/90-proarch-wallpapers`.

## If an image is missing from the switcher

Check the links for the current theme:

```sh
wallpaper_theme=$(cat "$HOME/.local/state/omarchy/current/theme.name")
ls -l "$HOME/.config/omarchy/backgrounds/$wallpaper_theme"
readlink -f "$HOME/.config/omarchy/backgrounds/$wallpaper_theme/spacex-liftoff.webp"
```

The resolved path should point to the image in the personal collection. A
deleted or moved collection image leaves a broken link; restore the image by
running the playbook with an existing source path.

To recreate missing links using the installed hook, run:

```sh
bash "$HOME/.config/omarchy/hooks/theme-set.d/90-proarch-wallpapers"
```

Close and reopen the wallpaper switcher after repairing the links. If you
changed the collection path or image list, run the playbook first so the
installed hook receives the new configuration.
